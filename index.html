Ccommandos GIT

  • git init- criar um repositorio
  • git add [file] :adiciona um arquivo no stage;
  • git status : exibe o estado do repositório
  • git commit -m "msg" :cria um commit
  • git log : exibe o commit do repositorio, da branch atual
  • git checkout referencia : recupera o conteudo de referencia para MK
