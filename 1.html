O que é HTML?

O HTML não é uma linguagem de programação, ele é uma linguagem de marcação, sendo muito usado para criar páginas web na internet, ele é focado em organizar conteúdo, como títulos, links e imagens, e para isso ele usa tags para facilitar esse processo.

Exemplos de onde se usa HTML:

  • Criação de sites e blogs
  • Estruturação de e-mails
  • Formulários de cadastro e login
  • Páginas de notícias e artigos
