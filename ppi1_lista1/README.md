# Projeto HTML e CSS - PPI1 Lista 1

## Descrição do projeto
Esse projeto é uma série de páginas em HTML com CSS externo, onde eu aprendi a criar listas, tabelas, formulários, links e usar imagens. Foi bem divertido de fazer, no começo foi meio difícil, mas fui pegando o jeito e consegui ver tudo funcionando bonitinho no navegador.

## Páginas do projeto
- `1.html` – Internet e Web  
- `2_http.html` – Protocolo HTTP  
- `3_tabela_uf.html` – Tabela de Estados do Brasil  
- `4_contato.html` – Formulário de Contato  
- `5_links.html` – Links para todas as páginas  
- `6_github.html` – Página sobre publicação no GitHub Pages  
- `style.css` – Estilo externo aplicado em todas as páginas
