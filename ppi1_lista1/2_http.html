Protocolo HTTP

O que é HTTP

O HTTP (HyperText Transfer Protocol) é o protocolo usado na web para comunicação entre o navegador e o servidor. Ele serve para enviar e receber informações, como páginas, imagens e dados. Quando você acessa um site, seu navegador faz uma requisição HTTP e o servidor responde com os dados.

Exemplo de requisição HTTP

Quando digitamos um site, acontece algo assim: 

GET /index.html HTTP/1.1
Host: www.exemplo.com
User-Agent: Mozilla/5.0
Accept: text/html

Explicação dos campos:

  • GET: tipo de requisição (buscar dados)
  • /index.html: recurso solicitado
  • HTTP/1.1: versão do protocolo
  • Host: endereço do servidor
  • User-Agent: identifica o navegador
  • Accept: tipo de resposta esperada

Exemplo de resposta HTTP

HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 1200

<html>
<body>Conteúdo da página</body>
</html>

Explicação dos campos:

  • 200 OK: indica sucesso
  • Content-Type: tipo do conteúdo retornado
  • Content-Length: tamanho da resposta

Resumo

O HTTP é essencial para a web, pois permite a troca de informações entre cliente e servidor. Sem ele, não seria possível acessar sites.
